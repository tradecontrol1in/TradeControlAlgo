# TradeControlAlgo
Copy the folder TradeControlAlgoToolKit to this location: D:\openalgo\strategies\TradeControlAlgoToolKit
Open app.py 
modify MASTER_DIR on line 26 if the path is different from above.
modify SETTINGS_FILE_PATH on line 34 if the path is different from above.

Open journal_settings.json
Search openalgo_api_key , replace "YOUR_OPEN_ALGO_API_KEY" with your openalgo api key from openalgo.
Check if other file paths are ok and as per your folder structure.

Check if requirements mentioned in requirements.txt are fullfiled. else install the same

Upload app.py to openalgo python strategies and run the same.

The app shall be available on http://127.0.0.1:5006/
